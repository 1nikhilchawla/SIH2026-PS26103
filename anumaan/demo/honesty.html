Model honesty — calibration, baselines, leakage

Numbers below come from a walk-forward split (train: months < 2025-01, test: months ≥ 2025-01). Re-running the trainer regenerates every figure.
SYNTHETIC DATA — method demonstration, not PAIMANA results. Every number on this page is computed by scripts/train_t1.py on data/synthetic/panel.csv (data_source: synthetic). Test split cutoff: 2025-01. Held-out base rate: 6.7%. LightGBM PR-AUC: 0.155.
Calibration is a deliverable, not a decoration. A "70% slip risk" on a project must be backed by a reliability check at the same horizon and sector. Below: how calibrated ANUMAAN is on the held-out months.

Leakage guard

Three checks. If any fail, the pipeline has read future information and the headline numbers above should not be trusted.

  • Real PR-AUC: 0.137  (no leak feature, this is the pipeline's honest score)
  • With synthetic leak feature: 0.985   (we add a feature that strongly correlates with the label; should jump near 1.0)
  • Shuffled training rows: 0.137   (permute training rows; should match real, otherwise features carry row-order signal)

Status: OK. Synthetic leak should drive PR-AUC to ~1.0; real pipeline should stay near real_pr_auc; shuffled_train should match real_pr_auc.

Censoring

T1 (slip_12m) is observable on every panel row because the horizon is fixed at 12 months. We do not drop right-censored projects. T2 (months_to_commissioning) is explicitly cut from this build per the delivery brief; if it is added later, it must use a discrete-time hazard model or a survival regressor.
